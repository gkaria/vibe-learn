Design notes

  • The dashed marker is drawn wherever harness_version or model changes. It lets you separate "the harness updated" from "the model changed."
  • The baseline is the same model and harness before the latest marker. It is not a rolling average, because a rolling average would absorb a regression and stop flagging it.
  • Flag rule (proposed default, configurable): the "since" row moves by 10 points or more for rates, or by 2 or more for counts, and both sides have at least 5 sessions.
  • The control sentence ("Codex stayed flat") only appears when another harness has 3 or more sessions in the same window.
  • Try Group by: Model. The change is still visible through the marker even though every Claude point is one color, which is why the default groups by harness.

Design notes

  • "Usual" means the mean for this model on this harness before the latest version change, the same baseline as the trend page, so the card and the trend never disagree about what is flagged.
  • Delta chips only appear on flagged tiles. Unflagged tiles still show the usual value so you can compare them yourself.
  • With fewer than 5 earlier sessions for the model, the tiles show raw numbers and a progress line, never a comparison.
  • The whole section is left out when health.jsonl does not exist, so the page is byte-identical to today's briefing.

Design notes

  • Counts are shown as 2/3, not percentages. With 3 runs per task, percentages would suggest more precision than the data has.
  • Each column compares only with the previous run of the same harness and model. Codex has no earlier bench, so it is never flagged.
  • Each run keeps its own vibe-learn log under .vibe-learn/bench/runs/<id>/, so /learn can explain what the assistant did differently.

Design notes

  • Nothing that spends tokens runs without a [y/N] prompt. --yes skips it for scheduled runs, and --dry-run prints the plan only.
  • The estimate comes from the tokens and cost your last bench reported. The final line shows the actual spend next to the estimate.
  • vibe-learn health is free: it only reads .vibe-learn/health.jsonl.
